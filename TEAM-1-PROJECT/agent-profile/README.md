# Orbit – AI Agent Profile

**Topic:** AI Agents → Agent Profile

## Research
1. **What it is:** A detail page for one AI agent: who it is, how well it performs, what it can do, and what it did recently.
2. **Where it is used:** AI automation platforms, support tools, team workspaces.
3. **Why it matters:** When an agent behaves oddly, people need one place to see its numbers, skills, permissions, and history.
4. **Patterns observed:** header with status, stat cards, tabs, bar charts, skill meters, activity feed, side panel with details.
5. **What this version adds:** blue, yellow and white design, animated numbers, bars and skill meters, pause/resume, opens any agent from the list using `?name=`, custom cursor, and no libraries.

## Run it
Open `index.html` in any modern browser. Or open it from the Agent List by clicking "View profile".
