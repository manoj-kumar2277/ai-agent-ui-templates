# Orbit – Agent Status Monitoring

**Topic:** AI Agents → Agent Status Monitoring

## Research
1. **What it is:** A live page that shows whether each AI agent is healthy, slow, or down.
2. **Where it is used:** Status pages, DevOps tools, AI platforms.
3. **Why it matters:** Agents run without a person watching, so problems must be spotted fast.
4. **Patterns observed:** a big overall banner, per-agent tiles, live response-time lines, 30-day uptime bars, incident list.
5. **What this version adds:** the banner changes by itself when agents are slow or down, live updating that can be paused, blue, yellow and white design, custom cursor, and no libraries.

## Run it
Open `index.html` in any modern browser.
